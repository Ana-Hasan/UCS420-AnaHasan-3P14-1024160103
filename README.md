# UCS420: Cognitive Computing Assignments

This repository contains my assignments for **UCS420: Cognitive Computing**, covering practical implementations of core concepts using Python and popular data science libraries.

### Topics Covered
- NumPy and Pandas
- Data preprocessing and analysis
- Natural Language Processing (NLP)
- Tokenization, stemming, and lemmatization
- Regex and text processing
- Statistical analysis and data visualization

**Language:** Python  
**Tools:** Google Colab, Jupyter Notebook, NumPy, Pandas, NLTK, Matplotlib

This repository serves as a collection of coursework, practical exercises, and implementations completed throughout the course.
